Quick Start (Step-by-step)

Follow these steps to go from configuration to a payable commission entry in under 10 minutes.

  1. Create a Commission Plan: Open Sales Commission → Configuration → Commission Plans and create a plan. Choose Tier Method (Flat or Marginal) and Commission On (Net Sales or Gross Profit).
  2. Define Tiers: Add tier lines with From Amount, To Amount (0/empty = no limit), and Rate (%).
  3. Set Product Cost (for Profit-based plans): If you use Gross Profit, ensure your products have a Cost (standard price) configured.
  4. Post an Invoice: Create a customer invoice, set Salesperson, then Post. The system creates/updates a Commission Ledger entry in Accrued.
  5. Register Payment: When invoice payment becomes In Payment or Paid, the ledger moves to Payable.

Operational Flow

1) Invoice Posted
Create/update ledger entry (Accrued). If invoice is a refund, clawback is created.
2) Payment Status
Ledger becomes Payable when invoice is In Payment or Paid.
3) Settlement Period
Review totals, lock period, export payout for payroll.

Technical Notes (What gets computed)

Base Amount
If the plan is Net Sales, the base is invoice untaxed amount. If the plan is Gross Profit, the base is Net Sales minus product cost (COGS).
Tier Logic
Flat: uses the highest tier where base ≥ From Amount. Marginal: splits base across tiers and sums each tier’s portion. To Amount can be empty/0 to represent “no limit”.
Ledger Status
Accrued after invoice is posted. Becomes Payable when payment is In Payment or Paid. Settlement periods can be locked to prevent edits.
Clawback
Credit notes generate negative ledger entries linked to the original invoice ledger (audit trail).
