Profit-Based Tiered Sales Commission

Automated ledger • tiered plans • auto-clawback

Replace spreadsheets with a transparent commission workflow: tiered plans, profit or revenue basis, auto-clawback on refunds, and a portal for sales reps.

Accrued → Payable

Automatically follows invoice payment status with audit-friendly ledger entries.

Auto-Clawback

Credit notes create negative commission entries linked to the original sale.

Tiered Plans

Flat or marginal tiers for predictable incentives across sales volumes.

Quick Start (5 steps)

  1. Create a Commission Plan: Sales Commission → Configuration → Commission Plans.
  2. Define Tiers: From Amount, To Amount (0/empty = no limit), Rate (%).
  3. Set Product Cost: required only for profit-based plans (Gross Profit).
  4. Post an Invoice: set Salesperson, then Post → ledger created in Accrued.
  5. Register Payment: payment becomes In Payment/Paid → ledger becomes Payable.
